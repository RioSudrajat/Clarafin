# Workspace Skills Rules for Antigravity

Whenever working on code or UI in this repository, follow these rules:

1. **Activate Relevant Skills**:
   - For UI design or frontend code: Consult `.agents/skills/antislop/SKILL.md` and `.agents/skills/antislop-ui/SKILL.md`.
   - When converting mockups/screenshots to code: Consult `.agents/skills/image-to-code/SKILL.md`.
   - When redesigning existing screens: Consult `.agents/skills/redesign-existing-projects/SKILL.md`.
   - For mobile layouts and avoiding overflows: Consult `.agents/skills/antislop-layoutmobile/SKILL.md`.
   - For accessibility and contrast: Consult `.agents/skills/antislop-human/SKILL.md`.
   - For writing complete code without placeholders: Consult `.agents/skills/full-output-enforcement/SKILL.md`.

2. **Style Precedence**:
   - The authoritative design system for this project is defined in `apps/mobile/docs/DESIGN_SYSTEM.md` (Halofin Neo-Brutalism: 2px black borders, hard drop shadows, Plus Jakarta Sans, Lime & Deep Teal palette).
   - Architectural and clean code guidelines are defined in `apps/mobile/docs/CODE_GUIDELINES.md` (Feature-First, orchestrator < 200 lines, modular widgets, zero static analysis issues).
   - For detailed timing and decision matrix on using workspace skills, refer to `apps/mobile/docs/SKILLS_GUIDELINES.md`.
